我们提供什么

从采集到一份可复核的数据

不只是一张图或一个分数。记录、计算、导出、备份，每一段都能追溯。

01 / 采集

放进口袋就能开始

不用配对设备，也不用穿传感器。起步检测通过后自动开始，记录中可以暂停、锁屏、防误触。信号中断会当场提示。

  • 裤子口袋 / 上衣口袋，固定位置
  • 屏幕常亮或息屏都支持
  • 断流、插值比例过高会标记
02 / 分析

不止步数和步频

步时变异、左右相位与支撑期不对称、eLow / eHigh 能量、PCI、转身次数与时长，都能在同一次记录里看到。

03 / 数据

导得出，也留得住

原始六轴数据一键导出 CSV，带表头和记录信息。需要长期保存时再逐条上传备份，不上传也能完整使用。

核心技术

把一步拆成信号，再拆成指标

三个关键设计，决定了这些数字在真实口袋里还剩多少可信度。

双频带能量分析

行走时，身体的低频摆动和落地的高频冲击混在同一段加速度里。 PDGait 把信号分成两个频带：eLow 反映重心起伏，eHigh 反映脚步冲击。 不需要先切出每一步，也能描述整段行走的状态。

频域分解 自适应基线 不依赖步事件

变异性与左右对称

走了多少步只是总量。每一步之间稳不稳、左右两边差多少，才更接近步态本身。 我们从步间期算变异系数，从左右周期算相位差与支撑期差异，再用 PCI 看两侧协调。

端侧计算，按需上传

所有滤波、峰值检测和指标计算都在手机里完成，离线也能用。 需要备份时，App 向云函数申请一个只对单条记录有效、十分钟过期的上传地址， 直接把文件写进私有存储桶。安装包里没有任何密钥。

数据安全

默认留在手机里

步态数据能反映一个人的行动习惯。采集和计算都在端侧完成，只有你主动点上传，那一条记录才会离开手机。

  • 本地优先原始信号和数据库都在应用私有目录，卸载即清除。
  • 预签名上传地址一次一签、十分钟失效，只能写这一条记录的路径。
  • 匿名标识只用随机安装 UUID，不读取 IMEI、Android ID 或位置。
1点「上传到云端」
2云函数校验口令，签发一次性 URL
3App 直接 PUT 到私有存储桶
4记录本地标记为已备份

上传失败不影响本地数据。可以换网络重试，也可以一直不传。

常见问题

你可能想问

需要注册账号吗？

不需要。装好就能记录，所有数据默认在本地。

支持 iPhone 吗？

目前只有 Android 版。iOS 的传感器权限和后台策略不同，还没有做。

数据会自动上传吗？

不会。只有你在记录详情页主动点「上传到云端」，那一条记录才会发出去。

步幅准不准？

步幅是根据步频和身高估算的，不是测距。看趋势可以，别拿它当卷尺。

能用来判断有没有病吗？

不能。这是运动数据记录工具，不是医疗器械，不提供诊断、治疗或监护相关的结论。
